# Day 4 · Clusters: one storm night, four scales

An interactive map of 6,547 lightning flashes seen by GOES-17's Geostationary Lightning Mapper over central British Columbia, 30 June 20:00 to 1 July 07:00 UTC 2021 (BC Albers, EPSG:3005). Zoomed out, flashes are coloured by convective cell found with space-time DBSCAN (radius, time scale and minimum count are sliders, with a k-distance plot). Zoomed in, each flash is drawn at its measured area with its groups, and an optional parallax whisker shows the satellite's view angle. A linked panel counts flash pairs by distance and time lag against a permutation null (a Knox-style surface) and moves it into the storm's frame: ERA5 steering wind (default), motion fitted from the cells (circular), or a custom velocity. A strip of hourly ERA5 covariates (CAPE, shear, lapse rate, steering wind) sits below.

Live: <https://cordilleran.github.io/MapChallenge2026/day-04.html>

## Files

- `site/day-04.qmd`: the page text.
- `site/js/day04.js`: the page: map, controls, k-distance plot, heat map, covariate strip, settings as JSON and the address.
- `site/js/day04core.js`, `site/js/day04worker.js`: the engine (DBSCAN, k-distance, cell statistics, fitted velocity, Knox surface; no DOM) and its Web Worker.
- `site/data/day04_glm.js`, `day04_era5.js`, `day04_base.js`, `site/img/day04_relief.webp`: prepared inputs (generated by the scripts below; do not edit).
- `scripts/01_fetch_era5.py`, `02_prepare_glm.py`, `03_era5_context.py`, `04_basemap.py`: fetch and prepare the inputs. `data/` holds the parquet and CSV analysis tables.
- `tests/core_test.js`, `tests/dbscan_vs_sklearn.py`: engine checks (hand cases, Knox against brute force, drift recovery on a simulated storm, same labels as scikit-learn).
- `tests/smoke_d4.py`: drives the built page in headless Chromium.

## Reproduce

Copy `env.example` and set `MC26_GLM_DIR` (GLM L2 LCFA files laid out as `<doy>/<hour>/*.nc`), `MC26_ERA5_DIR` (ERA5 files written by script 01) and `MC26_DAY04_RAW` (cache for terrain tiles and Natural Earth).

```
python3 day-04/scripts/01_fetch_era5.py
python3 day-04/scripts/02_prepare_glm.py
python3 day-04/scripts/03_era5_context.py
python3 day-04/scripts/04_basemap.py
node day-04/tests/core_test.js
python3 day-04/tests/dbscan_vs_sklearn.py
(cd site && quarto render day-04.qmd)
python3 -m http.server 8767 -d site/_site       # run in a separate terminal
python3 day-04/tests/smoke_d4.py http://127.0.0.1:8767/ /tmp/day04-shots   # needs websocket-client
fuser -k 8767/tcp                               # stop the server when done
```

## Limits

One night, one sensor, far off nadir (view angles 60 to 65 degrees): large pixels, a parallax shift and lower detection efficiency. GLM reports total lightning. One storm velocity for the whole night. The permutation null holds the places and times fixed, so it is unfair at the edges of the night; the band is not corrected for the 360 cells. Cells are not storms.
